Qaryat Al-Sidrah Studio

A desktop video production studio for the Qaryat Al-Sidrah animated series.

Qaryat Al-Sidrah Studio runs on its operator's own computer. It organises, edits, checks and exports the series' episodes and short videos.

When a video is finished, the studio can send it to the series' TikTok account as a draft, using TikTok Login Kit and the Content Posting API upload feature. The account owner reviews each draft in the TikTok app and decides whether to post it. The studio never publishes automatically and does not use Direct Post.
