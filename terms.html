2. What the App is

The App is a desktop video production studio. It runs locally on the operator's computer and is used to organise, edit, check and export videos for the Qaryat Al-Sidrah animated series. When a video is finished, the App can send it to a connected TikTok account as a draft, so the account owner can review it and decide whether to post it in the TikTok app.

The App is a private production tool. It is not offered for public sign-up, it has no web service of its own, and it does not run on our servers.

3. Who may use the App

4. TikTok sign-in

The App connects to TikTok through TikTok Login Kit for Desktop:

  1. The App opens TikTok's own authorisation page in your web browser. You sign in there and choose whether to grant access. The App never receives or stores your TikTok password.
  2. The App requests only these permissions (scopes): user.info.basic (your basic profile: an account identifier and display name) and video.upload (sending videos to your account as drafts). It does not request permission to publish posts directly.
  3. The sign-in uses PKCE (Proof Key for Code Exchange) with a SHA-256 code challenge and a random state value. The App checks state to make sure the answer came from the sign-in you started. TikTok returns you to a temporary address on your own computer (http://localhost:3455/callback/) that only the App listens on.
  4. TikTok then issues access tokens to the App. How they are stored is described in the Privacy Policy.

The App does not request TikTok's publishing permission (video.publish). You can withdraw access at any time (see section 11).

5. Drafts only, no automatic publishing

  • The App uploads videos to TikTok only as drafts, using TikTok's Content Posting API upload feature. TikTok delivers each upload to your TikTok inbox as a notification.
  • The App does not publish automatically. It does not use TikTok's Direct Post feature, does not set captions or privacy settings on TikTok, and does not schedule posts.
  • Each draft upload is started by the operator for one specific video. The App refuses to upload unless an approval note for that video is entered, and it records that note with the upload.
  • A draft becomes a post only if you open it in the TikTok app, review it, and post it yourself. Drafts you do not post stay unpublished.
